A code-verified pass across Individual User, NGO and Nursery — not a generic QA template. Checked items persist in this browser. Fix the risks below before working through the flows; they'll make the flows fail regardless of how carefully you click through.

01

Stripe has no live key. services/api/.env has no sk_... secret set — every checkout will fail until one is added, in test mode is fine for now.

02

Sapling QR/provenance is not built. The backend model (ArthSaplingUnit) exists, but there's no scan screen, no QR generator, and no expo-camera/QR package installed. Don't test for it — decide whether to build it or drop the "traceable sapling" claim from launch copy.

03

Delivery tracking may be one-sided. The rider's live GPS write path is real, but no screen was found that shows that live location to the buyer. Confirm before promising "live tracking" anywhere in the app.

04

Provenance silently drops. Neither a marketplace order nor an NGO bulk-requirement fulfillment attaches nurseryId to the Tree created when it's planted — the sapling's nursery origin is lost at the last step every time.
